Tutorial para aprender a programar en C#

C# es un lenguaje muy usado con la plataforma .NET para crear programas de consola, aplicaciones web, escritorio y videojuegos con Unity. En este tutorial aprenderás desde los conceptos más básicos, como variables y strings, hasta clases y objetos.

Ver manual en PDF

Variables y tipos de datos

Una variable es un espacio con nombre donde guardas información.

string nombre = "Juan";
int edad = 18;
double promedio = 17.5;
bool estudia = true;
  • string: guarda texto.
  • int: guarda números enteros.
  • double: guarda números decimales.
  • bool: guarda valores verdaderos o falsos.
  • char: guarda un solo carácter.
char letra = 'A';
bool tieneVida = true;

Para mostrar variables en pantalla:

string nombre = "Ana";
int edad = 16;

Console.WriteLine(nombre);
Console.WriteLine(edad);
Console.WriteLine("Me llamo " + nombre + " y tengo " + edad + " años.");

Strings

Un string sirve para guardar palabras, frases o cualquier texto.

string jugador = "Alex";
string mensaje = "Bienvenido al juego";

Puedes unir texto con variables usando el símbolo +.

string nombre = "Luis";
string saludo = "Hola, " + nombre;

Console.WriteLine(saludo);

También puedes contar los caracteres de un texto:

string palabra = "Programar";

Console.WriteLine(palabra.Length);

Para pedir texto al usuario:

Console.WriteLine("Escribe tu nombre:");
string nombre = Console.ReadLine();

Console.WriteLine("Hola, " + nombre);

Operadores básicos

int numero1 = 10;
int numero2 = 5;

Console.WriteLine(numero1 + numero2);
Console.WriteLine(numero1 - numero2);
Console.WriteLine(numero1 * numero2);
Console.WriteLine(numero1 / numero2);
  • ==: igual a.
  • !=: diferente de.
  • >: mayor que.
  • <: menor que.
  • >=: mayor o igual que.
  • <=: menor o igual que.
  • &&: y.
  • ||: o.

Condicionales

Los condicionales permiten que el programa tome decisiones.

int edad = 17;

if (edad >= 18)
{
    Console.WriteLine("Eres mayor de edad.");
}
else
{
    Console.WriteLine("Eres menor de edad.");
}

Recuerda: = sirve para asignar valores y == sirve para comparar valores. 

string usuario = "admin";

if (usuario == "admin")
{
    Console.WriteLine("Acceso permitido.");
}
else
{
    Console.WriteLine("Acceso denegado.");
}

Bucles

Bucle for

Se usa cuando sabes cuántas veces quieres repetir algo.

for (int i = 1; i <= 5; i++)
{
    Console.WriteLine("Nivel " + i);
}

Bucle while

Se usa mientras una condición siga siendo verdadera.

int vidas = 3;

while (vidas > 0)
{
    Console.WriteLine("Todavía tienes vidas.");
    vidas--;
}

Métodos

Un método es un bloque de código con nombre que puedes usar varias veces.

static void Saludar()
{
    Console.WriteLine("¡Hola!");
}

Saludar();
Saludar();

Un método también puede recibir datos:

static void Saludar(string nombre)
{
    Console.WriteLine("Hola, " + nombre);
}

Saludar("María");
Saludar("Pedro");

Clases y objetos

Una clase es una plantilla y un objeto es algo creado a partir de esa plantilla. 

class Jugador
{
    public string Nombre;
    public int Vida;
    public int Nivel;
}

Así se crea un objeto de la clase Jugador:

Jugador jugador1 = new Jugador();

jugador1.Nombre = "Leo";
jugador1.Vida = 100;
jugador1.Nivel = 1;

Console.WriteLine(jugador1.Nombre);

Método dentro de una clase

class Jugador
{
    public string Nombre;
    public int Vida;

    public void MostrarEstado()
    {
        Console.WriteLine(Nombre + " tiene " + Vida + " puntos de vida.");
    }
}
Jugador jugador1 = new Jugador();

jugador1.Nombre = "Sofía";
jugador1.Vida = 100;

jugador1.MostrarEstado();

Constructor

Un constructor asigna valores a un objeto al momento de crearlo.

class Jugador
{
    public string Nombre;
    public int Vida;

    public Jugador(string nombre, int vida)
    {
        Nombre = nombre;
        Vida = vida;
    }
}
Jugador jugador1 = new Jugador("Sofía", 100);

Console.WriteLine(jugador1.Nombre);

Ejercicios para practicar

  1. Pide al usuario su nombre y muestra un saludo.
  2. Pide dos números y muestra su suma.
  3. Pide una edad y determina si la persona es mayor de edad.
  4. Muestra los números del 1 al 10 usando un bucle for.
  5. Crea una clase Personaje con nombre, vida y ataque.
  6. Crea dos objetos de tipo Personaje y muestra sus datos.
  7. Agrega un método Atacar() que muestre un mensaje de ataque.
